# Aurelia Fragrance Catalog

A premium, editorial fragrance catalog experience built with Next.js, TypeScript, and Tailwind CSS. The site highlights curated fragrances, offers a polished shop experience, and includes an admin-facing overview for managing products, brands, and categories.

## Features

- Luxury home page with hero, featured products, brand highlights, new arrivals, and newsletter CTA
- Shop with searchable filters for brand, category, gender, availability, and sorting
- Product detail pages with notes, attributes, and related products
- About and contact pages with premium content and contact form UI
- Admin dashboard overview for catalog management
- Dark mode support, responsive layout, and SEO metadata

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Prisma ORM
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

## Notes

This starter uses local demo data for the catalog experience and a Prisma schema scaffold for future database integration.
